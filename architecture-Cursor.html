How a Marlow page becomes public

Each box is a persisted state. Approval sticks to a revision id. Publication appends an event. The public site never reads SQLite.

1. Draft revisionEditor save inserts an immutable revision. The previous approval is not copied.
2. ApprovalPublisher approves that revision id. A newer save needs a new approval.
3. Publication eventOne transaction writes the publication, moves the public pointer, and queues webhook outbox rows.
4. Public APIThe separate frontend requests only published, non-archived entries and renders the allowlisted blocks.

Scheduled jobs enter at step 3 after a worker claims the stored revision. Archive hides the entry without deleting events. Rollback appends another publication.

PreviewShort-lived token hash bound to one revision. Response is private and no-store.
WorkerLease plus a unique job id. A restart can finish the job once.
WebhooksSigned raw body from the outbox. Unsafe addresses are rejected. Retries are visible.
CacheNo shared cache. Public and preview responses both forbid storage.
